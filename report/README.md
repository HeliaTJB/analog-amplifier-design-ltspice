# Project Report

This folder contains the complete final report for the Electronics II project.

The report presents the design, analysis, simulation, and evaluation of a multi-stage analog power amplifier designed in LTspice.

## Report Contents

The report includes:

- Final circuit architecture
- DC operating-point analysis
- Bias analysis
- Output-stage design
- Global negative feedback design
- Comparison with and without feedback
- Output swing analysis
- Power and efficiency measurements
- Total power consumption
- Total harmonic distortion (THD)
- THD under noisy bias conditions
- Power-supply rejection ratio (PSRR)
- Differential input resistance
- Output resistance
- Real audio signal amplification
- Circuit cost analysis
- Final performance evaluation

## Main Results

Final measured and simulated results include:

- Closed-loop gain at 1 kHz: 19.88
- Maximum demonstrated output swing: 17.4 Vpp
- Output-stage efficiency: 72%
- Total power consumption: approximately 140 mW
- THD: approximately 0.028%
- THD with noisy bias sources: approximately 0.042%
- PSRR: approximately 120.45 dB
- Differential input resistance: 16.7 MΩ
- Output resistance: 0.473 Ω
- Total circuit cost: 145

For the complete calculations, figures, and simulation results, see the PDF file in this folder.
